# Cafe Campus System

Project website pemesanan cafe berbasis QR Code.

Struktur utama:
- server.mjs : backend server dan API
- public/ : frontend website
- public/assets/ : aset gambar
- data/ : penyimpanan data demo
- vendor/ : library QR Code yang digunakan

Fokus pengembangan:
- Customer ordering flow
- Admin dashboard
- QR table ordering
- Order status realtime

File demo/testing lama sudah dipisahkan agar project lebih bersih.
